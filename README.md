# FB2 Silero Audiobook

Локальное настольное приложение для преобразования русских книг FB2 в одну аудиокнигу MP3 с помощью Silero TTS v5.5. Основной и рекомендуемый интерфейс — [`audiobook_gui.py`](audiobook_gui.py): выбор книги, голоса, режима CPU/CUDA и выходной папки.

Проект является развитием [saabst/book-v2-audio](https://github.com/saabst/book-v2-audio). Спасибо авторам и участникам исходного проекта за основу приложения.

## Возможности

- чтение русских FB2 и последовательная обработка глав;
- локальная озвучка без отправки текста внешнему TTS-сервису;
- русская модель Silero `v5_5_ru` с голосами `eugene` и `xenia`;
- локальный синтез Silero на CPU или CUDA;
- пользовательский словарь произношений;
- сборка глав и итогового MP3 через `ffmpeg`;
- управляемая отмена кнопкой «Прервать»;
- безопасная остановка после текущего атомарного TTS-фрагмента;
- повторный запуск книги после отмены.

В кодовой базе присутствуют унаследованные экспериментальные движки и языки, которые в этой версии не тестировались: Edge TTS, Piper, Supertonic, а также en/ja/zh. Они не входят в заявленную проверенную область поддержки.

Скриншот намеренно не включён: имеющиеся изображения относятся к прежнему интерфейсу.

## Проверенная среда

Текущая версия проверена на:

- CachyOS / Linux;
- X11;
- Python 3.12;
- `ffmpeg`;
- русские FB2 и Silero TTS `v5_5_ru` на локальном PyTorch-окружении;
- выполнение на CPU и CUDA.

Другие операционные системы и графические окружения пока не объявляются проверенными.

## Требования

- Python `>=3.12,<3.13`;
- [uv](https://docs.astral.sh/uv/);
- `ffmpeg` и `ffprobe`, доступные через `PATH`;
- Tkinter для Python 3.12;
- для CUDA — совместимый NVIDIA-драйвер.

В CachyOS/Arch Linux системные компоненты обычно устанавливаются так:

```bash
sudo pacman -S python tk ffmpeg
```

## Установка через uv

Активация виртуального окружения не требуется. Все команды выполняются из корня репозитория.

Рекомендуемая установка с Silero:

```bash
uv sync --python 3.12 --extra silero
uv run python audiobook_gui.py
```

`uv sync` создаёт `.venv` автоматически и устанавливает версии из `uv.lock`. Для проверки окружения:

```bash
uv run python -c "import torch, torchaudio; print(torch.__version__, torchaudio.__version__, torch.cuda.is_available())"
uv run python -c "from src.core.tts_silero import SILERO_RU_MODEL_ID; print(SILERO_RU_MODEL_ID)"
ffmpeg -version
```

## Silero: CPU и CUDA

В проекте зафиксирована фактически проверенная комбинация:

- `silero-tts==0.0.5`;
- `torch==2.13.0`;
- `torchaudio==2.11.0`;
- русская модель `v5_5_ru`;
- голоса `xenia` (женский) и `eugene` (мужской).

Не следует менять номера `torch` и `torchaudio` только ради одинаковой версии: текущая комбинация согласована между `pyproject.toml`, `uv.lock` и проверенным окружением.

На Linux lock-файл может установить CUDA-сборку PyTorch. Она автоматически работает на CPU, если CUDA недоступна. Приложение выбирает устройство через `torch.cuda.is_available()`:

- включён флажок GPU и CUDA доступна — используется `cuda`;
- CUDA недоступна — используется CPU;
- флажок GPU отключён — Silero принудительно запускается на CPU.

CUDA-вариант требует совместимого драйвера. Выбор отдельной CPU-only или другой CUDA-сборки PyTorch меняет воспроизводимое окружение; перед такой заменой используйте актуальную официальную инструкцию [uv для PyTorch](https://docs.astral.sh/uv/guides/integration/pytorch/) и проверяйте совместимость обеих закреплённых зависимостей.

После установки модели и зависимостей синтез Silero выполняется локально. Интернет не нужен для последующих запусков уже установленной модели.

## Пользовательский словарь произношений

Silero загружает правила из:

```text
~/.audiobook-generator/pronunciations.toml
```

Пример:

```toml
[ru]
"SQLite" = "эс кью эль лайт"
"GUI" = "джи ю ай"
```

Правила применяются без учёта регистра только в Silero и не входят в репозиторий. Более длинные фразы имеют приоритет над короткими.

## Использование

1. Запустите `uv run python audiobook_gui.py`.
2. Выберите FB2-файл.
3. Выберите русский язык, Silero TTS и голос `eugene` или `xenia`.
4. Укажите выходную папку.
5. Для Silero при необходимости включите или отключите использование GPU.
6. Нажмите «Создать аудиокнигу».

Во время обработки кнопка «Прервать» запрашивает кооперативную отмену. Текущий TTS-фрагмент завершается штатно, новые фрагменты не запускаются, временные файлы текущего запуска удаляются. Отмена не считается ошибкой и после неё можно выбрать и запустить следующую книгу.

При закрытии окна во время работы приложение спрашивает: «Прервать обработку и выйти?» — и закрывается после фактической остановки worker.

## Известные ограничения

- Прогресс пока рассчитывается по этапам и главам. При переходе между этапами отображаемое значение может временно откатываться назад.
- Атомарный вызов TTS не прерывается посередине: отмена применяется на ближайшей безопасной контрольной точке.
- Качество синтеза зависит от выбранного голоса и исходной разметки FB2.
- Унаследованные движки Edge TTS, Piper, Supertonic и языки en/ja/zh в этой версии не тестировались.
- Поддержка вне CachyOS/Linux/X11 требует отдельной проверки.

## Конфиденциальность и пользовательские файлы

Книги, аудио, модели, логи, `.env`, локальные настройки и словарь произношений не должны попадать в Git. Соответствующие типы файлов исключены через `.gitignore`. Пользовательские настройки хранятся вне репозитория в `~/.audiobook-generator/`.

## Правовые условия

Используйте только книги, на обработку которых у вас есть необходимые права. Условия использования и лицензирования голосов и TTS-моделей определяются их поставщиками; пользователь самостоятельно отвечает за допустимость выбранного голоса и распространение созданной аудиокниги.
