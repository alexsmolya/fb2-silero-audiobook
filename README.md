# FB2 Silero Audiobook — локальная озвучка русских книг

*Offline Russian FB2-to-MP3 audiobook generator powered by Silero TTS v5.5.*

FB2 Silero Audiobook — программа для озвучки русских электронных книг и создания аудиокниг на Linux. FB2 обрабатывается нативно; EPUB, MOBI, AZW, AZW3, TXT, TXTZ, DOCX, ODT, RTF, HTML, HTM, HTMLZ и FBZ предварительно преобразуются системным Calibre в временный FB2. Затем приложение извлекает главы, преобразует русский текст в речь с помощью локальной Silero TTS v5.5 и собирает результат в один MP3. Основной и рекомендуемый интерфейс — простой GUI [`audiobook_gui.py`](audiobook_gui.py).

После установки зависимостей и первой загрузки модели озвучка работает без облачного TTS, API-ключей, квот и отправки текста книги внешнему сервису. Синтез можно выполнять на CPU или совместимой NVIDIA CUDA. Для первоначальной установки пакетов и загрузки модели доступ в интернет всё же требуется.

Проект является развитием [saabst/book-v2-audio](https://github.com/saabst/book-v2-audio). Спасибо авторам и участникам исходного проекта за основу приложения.

## Кому подойдёт

Проект подходит, если вы хотите:

- самостоятельно озвучить русскую книгу FB2 и получить MP3 для личного прослушивания;
- понять, как сделать аудиокнигу из FB2 или преобразовать FB2 в MP3 локально;
- использовать русский TTS без интернета после загрузки модели;
- не зависеть от облачных лимитов, квот и таймаутов;
- обрабатывать большие книги без повторной отправки текста в интернет;
- запустить офлайн-озвучку книг на Linux-компьютере с CPU или NVIDIA GPU;
- использовать локальную нейросеть Silero для озвучки русского текста;
- исправлять отдельные произношения и ударения через пользовательский словарь;
- использовать Silero TTS с графическим интерфейсом вместо написания собственного скрипта.

Это бесплатная локальная программа с открытым исходным кодом, но для её работы нужны совместимые зависимости и модель Silero с собственными условиями лицензирования.

## Что получается на выходе

- **Вход:** один FB2 либо один файл поддерживаемого Calibre-формата.
- **Обработка:** при необходимости локальная конвертация во временный FB2, извлечение глав через `FB2Parser`, разбиение текста на предложения, локальный TTS-синтез фрагментов и быстрая сборка каждой главы одним FFmpeg filter graph.
- **Выход:** один MP3-файл с названием книги.

Это автоматическая нейросетевая TTS-озвучка, а не студийная запись с участием человеческого диктора и звукорежиссёра. Результат предназначен прежде всего для личного использования с соблюдением прав на исходную книгу, голоса и модель.

## Поддерживаемые форматы

| Формат | Статус | Комментарий |
| --- | --- | --- |
| FB2 | Поддерживается нативно | Calibre не требуется |
| EPUB, включая `.kepub.epub` | Импорт через Calibre | Преобразуется во временный FB2 |
| MOBI, AZW, AZW3 | Импорт через Calibre | AZW4 не поддерживается |
| TXT, TXTZ | Импорт через Calibre | Подходит для обычного текста без сложной структуры |
| DOCX, ODT, RTF | Импорт через Calibre | Старый бинарный DOC не поддерживается |
| HTML, HTM, HTMLZ | Импорт через Calibre | Преобразуется во временный FB2 |
| FBZ | Импорт через Calibre | Преобразуется во временный FB2 |
| PDF, DjVu | Не поддерживаются | OCR и извлечение сложной разметки не реализованы |
| CBZ, CBR, CB7 | Не поддерживаются | Комиксы не входят в область проекта |

Calibre используется только как локальный импортёр: временный FB2 хранится до завершения обработки и удаляется после успеха, ошибки или отмены. Рядом с исходной книгой временные файлы не создаются. Сложное оформление может преобразоваться не идеально — для аудиокниги важны текст, абзацы, главы и метаданные.

## Почему локальная Silero

Проверенный сценарий проекта — озвучка FB2 через русскую модель Silero `v5_5_ru`. Практические преимущества такого подхода:

- синтез русского текста выполняется локально после загрузки модели;
- текст книги не отправляется внешнему TTS-сервису;
- нет облачных квот на объём книги и число запросов;
- доступны вычисления на CPU и CUDA;
- проверены голоса `eugene` и `xenia`;
- отдельные произношения можно корректировать пользовательским словарём;
- длительную обработку можно безопасно отменить кнопкой «Прервать».

Локальная Silero не гарантирует студийного качества или идеальных ударений и не позиционируется как объективно лучшая альтернатива облачным сервисам либо человеческому диктору.

## Проверенная среда

Текущая версия проверена на:

- CachyOS / Linux и X11;
- Python 3.12;
- `ffmpeg` и `ffprobe`;
- Calibre / `ebook-convert` для дополнительных форматов; проверено с Calibre 9.12.0;
- русских книгах FB2;
- Silero TTS `v5_5_ru` с голосами `eugene` и `xenia`;
- CPU и NVIDIA CUDA.

Windows, macOS, другие дистрибутивы и графические окружения пока не объявляются проверенными.

## Что проект пока не делает

- не читает PDF, DjVu, комиксы CBZ/CBR/CB7, AZW4, старый DOC или неоднозначные ZIP-архивы;
- не выполняет OCR для сканов и изображений;
- не клонирует человеческие голоса;
- не гарантирует безошибочные ударения во всех омографах и контекстах;
- не является редактором или студией мастеринга аудиокниг;
- не заявляет поддержку Windows и macOS без тестирования;
- не заявляет другие языки и TTS-движки проверенными.

В кодовой базе присутствуют унаследованные экспериментальные движки Edge TTS, Piper и Supertonic, а также языки en/ja/zh. В этой версии они нами не тестировались и не входят в заявленную область поддержки.

## Быстрый запуск

### Требования

- Python `>=3.12,<3.13`;
- [uv](https://docs.astral.sh/uv/);
- `ffmpeg` и `ffprobe`, доступные через `PATH`;
- Tkinter для Python 3.12;
- системный Calibre / `ebook-convert` для всех входных форматов, кроме FB2;
- для CUDA — совместимый NVIDIA-драйвер.

В CachyOS/Arch Linux системные компоненты обычно устанавливаются так:

```fish
sudo pacman -S python tk ffmpeg
```

Для импорта EPUB, MOBI, AZW/AZW3, TXT/TXTZ, DOCX, ODT, RTF, HTML/HTM/HTMLZ и FBZ установите Calibre:

```fish
sudo pacman -S calibre
```

Calibre не является Python-зависимостью проекта и не добавляется в `uv.lock`. Если вы работаете только с FB2, устанавливать Calibre не нужно.

Клонируйте репозиторий и установите проверенное окружение с Silero. Активация виртуального окружения не требуется:

```fish
git clone https://github.com/alexsmolya/fb2-silero-audiobook.git
cd fb2-silero-audiobook
uv sync --python 3.12 --extra silero
uv run python audiobook_gui.py
```

`uv sync` создаёт `.venv` автоматически и устанавливает версии из `uv.lock`. При первом запуске Silero может потребоваться загрузить модель. Для проверки окружения:

```fish
uv run python -c "import torch, torchaudio; print(torch.__version__, torchaudio.__version__, torch.cuda.is_available())"
uv run python -c "from src.core.tts_silero import SILERO_RU_MODEL_ID; print(SILERO_RU_MODEL_ID)"
ffmpeg -version
```

## Ярлык в меню приложений

После подготовки клона и `.venv` приложение можно зарегистрировать в меню текущего пользователя:

```fish
.venv/bin/python scripts/install_desktop.py
```

Установщик создаёт управляемый ярлык `fb2-silero-audiobook.desktop` в пользовательском XDG-каталоге приложений. Root и `sudo` не нужны. Это только регистрация уже установленного клона: скрипт не копирует репозиторий, не создаёт `.venv` и не устанавливает зависимости.

Для удаления ярлыка:

```fish
.venv/bin/python scripts/install_desktop.py --uninstall
```

Удаление не затрагивает проект, окружение, настройки, модели, книги и аудиофайлы. Ярлык содержит абсолютный путь к текущему клону, поэтому перенос или удаление каталога проекта сломает запуск из меню. После переноса запустите установщик ещё раз из нового расположения.

## Диагностические журналы запусков

Файловая диагностика включена по умолчанию. Каждый обработанный запуск GUI создаёт отдельный машиночитаемый JSONL-журнал в `$XDG_STATE_HOME/fb2-silero-audiobook/logs/`, а если `XDG_STATE_HOME` не задан — в `~/.local/state/fb2-silero-audiobook/logs/`. Имена собственных журналов начинаются с `fb2-silero-audiobook-run-`; ротация не затрагивает другие JSONL-файлы в этом каталоге.

Во время обработки файл имеет суффикс `.jsonl.part`, и процесс удерживает на нём межпроцессную блокировку. После успеха, обработанной отмены или ошибки он атомарно становится `.jsonl`. Незавершённый собственный `.part`, оставшийся после аварийного завершения приложения или системы, при следующем запуске переименовывается в `.incomplete.jsonl` только после безопасного получения блокировки; активный журнал другого процесса не трогается.

По умолчанию хранятся не более 30 завершённых или incomplete-журналов приложения общим объёмом до 250 МиБ; строгий предельный размер одного журнала — 25 МиБ. Перед каждой записью проверяется точный UTF-8-размер, а для единственной пары `run_terminal`/`run_summary` заранее резервируется место. При исчерпании обычной области события отбрасываются и журнал помечается как усечённый. При ошибке самого файлового ввода-вывода диагностика остаётся fail-open для синтеза, но завершённая terminal-пара и атомарное переименование уже не могут гарантироваться.

Журнал содержит события `run_start`, `stage_start`/`stage_end`, `tts_segment`, `run_terminal` и `run_summary`, параметры среды, длительности этапов, обезличенные размеры TTS-фрагментов, характеристики аудио и системные метрики. Полный текст книги, API-ключи, токены, пароли, keyring, полный конфиг и полные runtime-пути не записываются. Тексты ошибок централизованно очищаются от credentials, секретоподобных значений и известных source/output/work/temp-путей. Безопасные название, автор и basename книги сохраняются. Ошибка диагностики не останавливает синтез и выводится в GUI одним предупреждением.

Чтобы найти последний завершённый журнал в fish:

```fish
set log_dir (test -n "$XDG_STATE_HOME"; and echo "$XDG_STATE_HOME/fb2-silero-audiobook/logs"; or echo "$HOME/.local/state/fb2-silero-audiobook/logs")
ls -t $log_dir/fb2-silero-audiobook-run-*.jsonl | head -n 1
```

Для анализа производительности передайте один найденный `.jsonl`-файл вместе с кратким описанием запуска. Публиковать весь каталог не требуется.

## Управление моделями Silero TTS (CLI)

Локальные модели Silero TTS хранятся вне `.venv` в пользовательском хранилище `~/.local/share/fb2-silero-audiobook/models/`. Для управления моделями и проверки обновлений доступны CLI-команды:

```fish
# Показать список локально установленных моделей
uv run python main.py models list

# Показать текущую активную модель
uv run python main.py models active

# Информация по конкретной модели
uv run python main.py models info v5_5_ru

# Безопасная миграция модели из .venv в пользовательское хранилище
uv run python main.py models migrate --dry-run

# Проверить наличие новых официальных моделей (только инспекция, без скачивания)
uv run python main.py check-updates

# Безопасное скачивание новой модели (новые модели регистрируются с active=false)
uv run python main.py models download --dry-run
uv run python main.py models download --yes

# Изолированный smoke-test обязательных голосов (eugene и xenia)
uv run python main.py models test v5_5_ru
uv run python main.py models test v5_5_ru --all-speakers

# Безопасная активация модели (требует успешного smoke-test)
uv run python main.py models activate v5_6_ru --dry-run
uv run python main.py models activate v5_6_ru --yes

# Откат (rollback) к предыдущей заведомо рабочей модели
uv run python main.py models rollback --dry-run
uv run python main.py models rollback --yes
```

- **Безопасность скачивания:** Скачивание новой модели регистрирует её с статусом `active=false` и не меняет текущую активную модель.
- **Обязательные голоса:** Активация требует успешного прохождения smoke-test для обязательных русских голосов `eugene` и `xenia`.
- **Сохранение моделей:** При откате (`rollback`) бинарные файлы ранее загруженных моделей сохраняются на диске.

## Как озвучить книгу

1. Запустите `uv run python audiobook_gui.py`.
2. Выберите FB2 либо один из перечисленных форматов импорта.
3. Выберите русский язык, Silero TTS и голос `eugene` или `xenia`.
4. Укажите выходную папку.
5. При необходимости включите или отключите использование GPU.
6. Нажмите «Создать аудиокнигу».

Для FB2 обработка запускается сразу. Остальные разрешённые форматы сначала локально преобразуются в FB2 через `ebook-convert`; после этого используется тот же проверенный FB2 → TTS → MP3 пайплайн. Итоговый MP3 получает название из метаданных книги, а не из имени временного файла.

Если Calibre отсутствует, FB2 продолжает работать. Для дополнительного формата приложение покажет команду установки. PDF, DjVu, комиксы, AZW4, старый DOC, ZIP, CHM, LIT и PDB намеренно отклоняются.

Во время обработки общий индикатор учитывает объём текста глав и монотонно проходит подготовку, синтез, сборку глав и финальную проверку. Кнопка «Прервать» запрашивает кооперативную отмену: текущий атомарный TTS-фрагмент завершается штатно, новые фрагменты не запускаются, а интерфейс после остановки позволяет начать другую книгу. При закрытии окна приложение спрашивает: «Прервать обработку и выйти?» — и ждёт фактического завершения worker.

## Silero: CPU и CUDA

В проекте зафиксирована фактически проверенная комбинация:

- `silero-tts==0.0.5`;
- `torch==2.13.0`;
- `torchaudio==2.11.0`;
- русская модель `v5_5_ru`;
- голоса `xenia` (женский) и `eugene` (мужской).

Не следует менять номера `torch` и `torchaudio` только ради одинаковой версии: текущая комбинация согласована между `pyproject.toml`, `uv.lock` и проверенным окружением.

На Linux lock-файл может установить CUDA-сборку PyTorch. Она автоматически работает на CPU, если CUDA недоступна. Приложение выбирает устройство через `torch.cuda.is_available()`:

- включён флажок GPU и CUDA доступна — используется `cuda`;
- CUDA недоступна — используется CPU;
- флажок GPU отключён — Silero принудительно запускается на CPU.

CUDA-вариант требует совместимого драйвера. Выбор отдельной CPU-only или другой CUDA-сборки PyTorch меняет воспроизводимое окружение; перед такой заменой используйте актуальную официальную инструкцию [uv для PyTorch](https://docs.astral.sh/uv/guides/integration/pytorch/) и проверяйте совместимость обеих закреплённых зависимостей.

## Пользовательский словарь произношений

Silero загружает правила из:

```text
~/.audiobook-generator/pronunciations.toml
```

Пример для русской книги:

```toml
[ru]
"открыла глаза" = "открыла глаз+а"
"поднял глаза" = "поднял глаз+а"
```

Можно добавлять собственные слова и фразы, например имена персонажей, географические названия и контекстные варианты ударения. Правила применяются без учёта регистра только в Silero и не входят в репозиторий. Более длинные фразы имеют приоритет над короткими.

## Известные ограничения

- Оценка оставшегося времени зависит от скорости выбранного TTS и размера глав; общий числовой прогресс остаётся монотонным, но ETA может меняться.
- Атомарный вызов TTS не прерывается посередине: отмена применяется на ближайшей безопасной контрольной точке.
- Качество синтеза зависит от выбранного голоса и исходной разметки FB2.
- Calibre может упростить сложное оформление исходной книги; при импорте приоритетны текст, абзацы, главы и метаданные.

## English summary

FB2 Silero Audiobook is a Russian ebook audiobook generator for Linux. FB2 works natively; EPUB, MOBI, AZW/AZW3, TXT/TXTZ, DOCX, ODT, RTF, HTML/HTM/HTMLZ, and FBZ are imported through the system `ebook-convert` tool and then use the same FB2-to-MP3 pipeline. It combines offline Russian text-to-speech, local Russian TTS for Linux, and a simple Silero TTS GUI.

The verified speech scope remains Russian books on Linux with Silero `v5_5_ru`, `eugene`, and `xenia`. PDF, DjVu, comics, Windows, macOS, Edge TTS, Piper, Supertonic, and en/ja/zh are not verified as supported in this release.

## Конфиденциальность и пользовательские файлы

Основной GUI отключает унаследованную генерацию AI-комментариев и не требует API-ключа. При локальном Silero-синтезе текст книги не отправляется внешнему TTS-сервису. Интернет нужен для установки зависимостей и первоначальной загрузки модели; сетевое поведение унаследованных экспериментальных компонентов может отличаться.

Книги, аудио, модели, логи, `.env`, локальные настройки и словарь произношений не должны попадать в Git. Соответствующие типы файлов исключены через `.gitignore`. Пользовательские настройки хранятся вне репозитория в `~/.audiobook-generator/`.

## Правовые условия

Используйте только книги, на обработку которых у вас есть необходимые права. Условия использования и лицензирования голосов и TTS-моделей определяются их поставщиками; пользователь самостоятельно отвечает за допустимость выбранного голоса и распространение созданной аудиокниги.

Код проекта распространяется по исходной лицензии [MIT](LICENSE).
